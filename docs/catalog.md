# Catalog

What the IDC has been asked to build, and what can be asked for. This page is
generated from the repository on every site build (`scripts/site_catalog.py`),
so it always matches `main`.

A request is not the same as published data: a request is built after it is
merged and published by a maintainer after that. Whether a version is actually
available is answered by a Galaxy's data table, linked for each table below;
[Checking the status of a request](requesting-reference-data.md#checking-the-status-of-a-request)
explains how to follow one.
